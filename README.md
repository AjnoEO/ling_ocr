# movima_bible_ocr
Библия на [мовиме](https://glottolog.org/resource/languoid/id/movi1243) после прогона через OCR (автоматическую детекцию текста) в Google Chrome

Оригинал: [scriptureearth.org](https://www.scriptureearth.org/data/mzp/PDF/mzp26021Movima.pdf)

## Известные проблемы

- ɬ → ł, l, t
- ń → n, h, m
- ḿ → m, rm
